# 🍽️ Bonvera.food - Strasbourg Türk Mutfağı

Strasbourg'da günlük taze üretim Türk mezeleri, içli köfte ve sarmalar sunan modern web sitesi.

## 🌟 Özellikler

- **Responsive Tasarım**: Mobil ve masaüstü uyumlu
- **Modern UI/UX**: Kullanıcı dostu arayüz
- **Online Sipariş**: Kolay sipariş ve sepet sistemi
- **SEO Optimized**: Arama motorları için optimize edilmiş
- **PWA Ready**: Progressive Web App özellikleri
- **Hızlı Yükleme**: Optimize edilmiş görseller ve kod

## 🍴 Menü Kategorileri

### Mezeler
- Cacık, Ezme, Acılı Humus
- Amerikan Salatası, Barbunya Salatası
- Domates Kurusu, Fava, Grek Salatası
- Mantar Salatası, Mor Lahana
- Muammara, Muhteber, Pancar Salatası
- Patlıcanlı Humus, Şakşuka, Tarator

### İçli Köfte
- Kızarmış İçli Köfte
- Çiğ İçli Köfte

### Sarmalar
- Yaprak Sarma
- Kabak Sarma
- Patlıcan Sarma

## 🚀 Kurulum

1. **Repository'yi klonlayın:**
```bash
git clone https://github.com/yourusername/bonvera-food.git
cd bonvera-food
```

2. **HTTP Server başlatın:**
```bash
# Python ile
python -m http.server 8000

# Node.js ile
npx serve -s . -l 8000

# PHP ile
php -S localhost:8000
```

3. **Tarayıcıda açın:**
```
http://localhost:8000
```

- **HTML5**: Semantic markup
